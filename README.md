# Чанти слушает v0.3 🎧

**Два полностью отдельных режима.**

## Музыка — для текущего музыкального разговора

Один раз дай Android специальный доступ к уведомлениям (широкое право, несмотря на фильтрацию в коде). Нажми **«Чанти, слушаем!»** и открой Яндекс Музыку. Программа автоматически ведёт локальный журнал смены треков, пауз, прослушанного времени, быстрых переходов и оценок **если они опубликованы как MediaMetadata.USER_RATING**. Не считать короткое прослушивание дизлайком.

Требуемый итог — автоматическая доставка **в конкретный существующий разговор ChatGPT** — **не реализован**: у приложения нет публичного интерфейса для фоновой публикации туда сообщений. Чтобы продолжить разговор, можно скопировать **весь журнал одним действием после сессии**, не делиться каждой песней. Приложение не содержит API-ключей и не использует Интернет.

## Магир — для отдельного разговора

Нажми **«Начать запись Магира»** → разреши микрофон → записывай игру с видимым системным уведомлением. Нажми «Остановить запись», затем «Сохранить запись для другого чата», выбери папку. Полученный .m4a можно загрузить в отдельный чат Магира вручную. Не записывай людей без их согласия.

## Установка

Debug APK собирается GitHub Actions. GitHub не гарантирует одинаковую debug-подпись между сборками: если предыдущая v0.2 подписана другим ключом, сначала удали **«Чанти слушает 0.2»**, затем установи v0.3. Старое приложение v0.1 тоже можно удалить. Поскольку идентификатор приложения тот же, новая v0.3 не создаёт третью копию рядом с v0.2.

## Приватность и ограничения

- Данные о музыке и записи хранятся на телефоне; доступ к Интернету не запрашивается.
- Android Notification Listener **технически имеет доступ ко всем уведомлениям**, но код не читает чужие сообщения — только событие с пакетом Яндекс Музыки и MediaSession.
- Невозможно гарантировать обнаружение всех быстрых переключений/лайков: зависит от данных, которыми делится версия Яндекс Музыки.
- Запись «Магира» использует микрофон, **не** захват аудио других приложений.
- Связать этот APK с конкретным чатом можно лишь через поддерживаемый механизм платформы; автоматическое сообщение в существующий ChatGPT-чат не заявляется как готовая функция.
