# Чанти слушает v0.7 — исправление загрузки Whisper Small

Это исправление v0.6, а не новый набор функций. Русская офлайн-расшифровка Whisper и пятиминутная запись «Магира» сохранены.

**Исправлено:**
- Повторная загрузка с сохранённого места при обрыве соединения.
- Запасной источник модели в Hugging Face, если основной сервер не ответил.
- Отдельный экран восстановления: открыть официальную модель в браузере и выбрать уже скачанный ggml-small.bin из памяти телефона.
- Импорт проверяет длину (487601967 байт) и SHA-256 (1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b), только после совпадения файл принимается.
- Вместо технических ошибок в некоторых сетевых ситуациях отображается русское пояснение.

**Как использовать:**
1. Установить v0.7 (рядом с v0.6, не удаляя прежнюю запись).
2. Записать короткий фрагмент «Магира», остановить запись и нажать «Точная расшифровка Whisper».
3. Если встроенное скачивание опять даст ошибку: кнопка «Не удалось скачать модель? Исправить» → «Скачать в браузере». Сохранить файл ggml-small.bin → та же кнопка → «Выбрать файл».
4. После проверки SHA-256 расшифровка запускается автоматически. Аудио обрабатывается только локально.

**Важно:** тот факт, что APK собрался и тесты Gradle прошли, не гарантирует доступность серверов на любом телефоне или качество записи. Сообщения в обычный мобильный ChatGPT-чат по-прежнему автоматически не передаются. Доступ к уведомлениям Android широкий и остаётся необязательным. Запись «Магира» без согласия участников не вести.

**Техническое примечание:** из-за неподписанных стабильным ключом ранних debug APK версия 0.7 имеет отдельный applicationId. После успешного теста следует организовать постоянную release-подпись, чтобы обновления ставились поверх одной версии, а не множили значки приложений.
