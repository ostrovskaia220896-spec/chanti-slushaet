# Чанти слушает — версия 0.6 (тест качества распознавания)

## Главное изменение: Whisper Small на телефоне
- В режиме «Магир» запись остаётся отдельной от музыки и сохраняется по ~5 минут в m4a.
- Кнопка **«Точная расшифровка Whisper»** однократно предлагает скачать мультиязычную модель Whisper Small (~488 МБ) с официальной страницы ggerganov/whisper.cpp на Hugging Face.
- Приложение проверяет её SHA-256, умеет продолжать оборванную загрузку и не отправляет записи в Интернет.
- Каждый m4a-фрагмент преобразуется в **WAV PCM16 16000 Гц mono**, как требует реальный исходный API Android-библиотеки.
- Модель загружается в память и распознаёт фрагменты на телефоне, с временными отметками на основе Whisper.
- Отдельные результаты `part_XXXX.whisper.txt` сохраняются сразу после каждой части. Готовые части не распознаются повторно, итоговый файл — `transcript_whisper_ru.txt`.
- Экспорт TXT/ZIP использует новую расшифровку. Исходные m4a не удаляются после распознавания.

## Почему не серверная Vosk на 1.8 ГБ
В официальном списке Vosk модель `vosk-model-ru-0.42` помечена как **для серверов**; большая модель может использовать до 16 ГБ ОЗУ, а не только дисковое место. На мобильном телефоне риск сбоя выше. Whisper Small — более разумная первоначальная попытка улучшить качество русского текста без платных сервисов. Качество нужно проверить реальным экспериментом.

## Тестирование
1. Установить v0.6 **рядом с 0.5**. Оно имеет другой applicationId, поэтому данные старого приложения не переносятся.
2. Записать 2–5 минут речи, желательно немного текста с именами из «Магира».
3. Остановить запись, нажать кнопку расшифровки, согласиться скачать ~488 МБ по Wi-Fi (один раз).
4. Дождаться окончания. Экспортировать `transcript_whisper_ru.txt` и исходную запись. Сравнить с Vosk 0.5 на одной записи или с оригиналом.
5. Лишь после короткого успешного теста доверять длинные сессии.

## Видео
Когда медиасессия YouTube/Кинопоиска/Иви не передаёт название, приложение не добавляет фиктивный заголовок в историю. Для видео-уведомлений медиа-типа пытается использовать заголовок, если он действительно опубликован Android.

## Ограничения
- **Нет фоновой отправки в существующий мобильный чат ChatGPT**: такой доступ стороннему APK не предоставлен. Музыкальный журнал нужно передавать целиком вручную. «Магир» — в другой чат.
- Whisper на телефоне может потребовать много памяти, сильно нагреть устройство и распознавать заметно медленнее реального времени; обработка 2–4 часов не гарантируется за одну сессию. Есть продолжение с сохранённых частей.
- Программа не разделяет говорящих автоматически и может ошибаться в именах/фэнтезийных терминах.
- В эксперименте с отключением экрана 0.5 получилось более 20 минут. Но дальнейшая проверка устойчивости необходима.
- Android имеет широкий доступ к уведомлениям, только если пользователь явно разрешает автоматическое наблюдение за музыкой/видео.
- В версии 0.6 код впервые подключает стороннюю бинарную Android-библиотеку whisper.cpp (MIT); она пока не протестирована на конкретной модели телефона.
- Вторая отдельная Vosk-расшифровка оставлена в исходном проекте, но UI теперь запускает Whisper.
