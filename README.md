# Чанти слушает — 1.0.0-rc1

Android-приложение с двумя независимыми потоками:
- **Музыкальный дневник:** Android MediaSession, доступные события play/pause/skip и рейтинги/лайки, метаданные поддерживаемых видеоплееров.
- **Миры Магира:** фоновая запись AAC/M4A фрагментами по пять минут и локальная расшифровка Whisper Small.

## Стабильный идентификатор
- Application ID: `ru.chanti.slushaet`
- Version code: `100`
- Version name: `1.0.0-rc1`

Пакеты `ru.chanti.slushaet.v06/.v07/.v08` — отдельные экспериментальные приложения. Новая установка не может читать их приватные папки. Экспортируйте ZIP/TXT из старых версий и импортируйте в 1.0; не удаляйте старые приложения до проверки резервных копий.

## Сохранность сессий
- Каждая запись получает уникальную папку; совпадение временной метки не перезаписывает предыдущую.
- Текущий аудиофрагмент пишется в `.m4a.pending` и переименовывается в `.m4a` только после успешного завершения MediaRecorder.
- Незавершённый файл сохраняется для диагностики и ZIP-резерва, но не передаётся Whisper как готовое аудио.
- Выбранная сессия, активная запись и задача Whisper — независимые состояния.
- Whisper работает одним процессом за раз; другие задачи стоят в сохраняемой очереди. Готовые части являются checkpoint и не обрабатываются повторно.
- Сводный TXT заменяется через временный файл и резервную копию. При старте восстанавливаются backup-файлы.
- ZIP/TXT экспортируются из выбранной сессии. Импорт принимает только известные плоские имена файлов и ограничивает число/размер файлов.

## Сборка и подпись
GitHub Actions запускает unit-тесты и собирает debug APK для технической проверки. **Debug APK не предназначен для установки поверх предыдущей версии**: временный runner не хранит постоянную подпись.

Подписанный release APK создаётся после настройки GitHub Actions repository secrets:
- `CHANTI_KEYSTORE_BASE64` — base64 постоянного Android keystore;
- `CHANTI_KEYSTORE_PASSWORD`;
- `CHANTI_KEY_ALIAS`;
- `CHANTI_KEY_PASSWORD`.

Keystore не хранится в репозитории. Один и тот же ключ должен использоваться для всех будущих обновлений `ru.chanti.slushaet`.

## Перенос
1. Из старой версии экспортировать ZIP с аудио и TXT.
2. Установить подписанный `ru.chanti.slushaet`.
3. Импортировать ZIP в «Миры Магира»; при необходимости добавить отдельный TXT.
4. Сверить число фрагментов и открыть расшифровку. Только после проверки решать, можно ли удалять старые приложения.

## Честные ограничения
- Whisper Small работает локально, но пока не различает участников (диаризация не реализована).
- Во время распознавания показываются этап, номер части и прошедшее время; процент внутри нативного вызова не выдумывается.
- Яндекс SpeechKit рассматривается как будущая официальная облачная альтернатива с явным согласием и пользовательским ключом. Внутренние интерфейсы Алисы не извлекаются.
- Приложение не может самостоятельно дописать сообщение в произвольный уже открытый чат ChatGPT. Музыкальный дневник можно скопировать; Chanti Bridge — отдельный канал обмена.
- Название видео доступно только если плеер передаёт его через Android MediaSession/уведомление. Видеоряд и звук видео не считываются.
- Длительная запись, блокировка экрана и обновление поверх предыдущей подписанной сборки требуют проверки на целевом телефоне.

Сценарии приёмки описаны в `SESSION_DESIGN_v10.md` и issue #3. Не выпускать стабильную сборку до прохождения тестов записи, очереди, восстановления, экспорта/импорта и обновления поверх той же подписи.
