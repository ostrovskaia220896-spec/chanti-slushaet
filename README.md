# Чанти слушает 🎧 — Android v0.2

Экспериментальное Android-приложение для обсуждения песен из Яндекс Музыки в ChatGPT.

## Два режима

1. **Безопасный (рекомендуется).** В Яндекс Музыке открой песню → **Поделиться** → **Чанти слушает 0.2**. Android передаст ссылку/текст только по твоему действию. Доступ к SMS, уведомлениям, аккаунту и аудио не требуется.
2. **Автоматический (необязательный).** Может читать название песни из медиасистемы Android. Для него Android запрашивает широкое право читать **все уведомления** (даже если наш код использует лишь сведения Яндекс Музыки). На некоторых телефонах доступ блокируется как опасный. Не рекомендуется отключать защиту телефона ради этого режима.

Текст после получения песни можно **скопировать**, затем открыть именно ваш прежний разговор ChatGPT и вставить сообщение. Приложение само не отправляет сообщения и не умеет открыть конкретный разговор автоматически.

## Установка

- APK собирает GitHub Actions: вкладка **Actions** → **Build Android APK** → последний успешный запуск → **Artifacts** → `Chanti-Slushaet-APK`.
- В этой экспериментальной сборке Android ID приложения изменился на `ru.chanti.slushaet.v2`, потому что старый debug APK был подписан другим ключом. Поэтому v0.2 можно установить рядом с v0.1. После проверки новой версии старую можно удалить (история v0.1 автоматически не переносится).
- Если Яндекс Музыка прислала только URL, приложение передаст URL, не пытаясь угадывать название песни.

Приложение не имеет разрешения INTERNET, сохраняет историю автоопределения и последнюю переданную ссылку локально. Данные передаются в ChatGPT **только после действия пользователя** (копирование/вставка).

## Ограничения

- У ChatGPT нет общего с Яндекс Музыкой аудиопотока: приложение не слушает и не анализирует звучание песни.
- Не гарантируется, что конкретная версия Яндекс Музыки покажет приложение в меню «Поделиться» на каждой прошивке; в таком случае можно вручную вставить ссылку/название.
- Для последующих обновлений нужна постоянная подпись APK, а не случайный debug-ключ, иначе Android снова не даст обновить установленное приложение поверх старого.
