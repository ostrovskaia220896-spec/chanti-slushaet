# Чанти слушает 0.5 🎧 — экспериментальное Android-приложение

## Режим музыки (для этого чата)
Одна кнопка **«Чанти, слушаем!»**. После первоначального предоставления системного разрешения приложение ведёт **локальный** журнал Яндекс Музыки: начало песен, паузы, время прослушивания, переключения и лайки, если медиаплеер публикует пользовательский рейтинг. Подсчёт короткого прослушивания не означает, что песня не понравилась.

**Ограничение:** обычное стороннее приложение не имеет поддерживаемого способа без участия пользователя записывать события именно в ранее открытый мобильный разговор ChatGPT. Кнопка копирования общего дневника остаётся. Автоматической фоновой отправки нет.

## Медиаданные видео
При включённом режиме наблюдения приложение также отслеживает **метаданные** активных медиасессий известных видеоплееров: YouTube, Кинопоиск, Иви. Поддержка зависит от того, публикует ли плеер название и состояние. Картинка, видео- и аудиопоток не считываются.

## Запись «Миров Магира» (для ДРУГОГО чата)
Отдельная видимая кнопка запускает foreground microphone service. Запись сохраняется как последовательность AAC/M4A фрагментов примерно **по 5 минут**. Смена фрагмента может дать небольшой разрыв аудио. Готовые части сохраняются независимо: если Android завершит приложение, недописанный текущий фрагмент может повредиться, но уже завершённые фрагменты остаются.

Приложение поддерживает выключение экрана после запуска службы на видимом экране и удерживает CPU wake lock во время сессии. **Это не гарантия** устойчивой четырёхчасовой записи на любой прошивке: требуется реальное испытание.

## Офлайн-расшифровка русского аудио
После остановки «Магира» нажать **«Расшифровать на телефоне»**. При первой попытке пользователь явно соглашается скачать по HTTPS [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models.html) (~45 МБ, Apache 2.0). Далее распознавание на устройстве; приложение использует библиотеку Vosk Android 0.3.47, MediaCodec/MediaExtractor для локальной декодировки M4A, сохранение промежуточных результатов и отдельный `transcript_ru.txt`. Расшифровка ведётся по завершённым частям, при повторном запуске продолжается после последней успешно обработанной части.

**Качество распознавания:** маленькая модель неточна в собственных именах, фэнтезийных терминах и перекрывающейся речи; говорящие не разделяются, временные метки приблизительные. Не заменяет исходные записи. На первом запуске нужна свободная память и Интернет для модели; дальше Интернет для расшифровки не требуется.

## Экспорт
- **Сохранить аудио + текст ZIP** — выгружает сегменты m4a и, если есть, transcript_ru.txt.
- **Сохранить расшифровку TXT** — текст отдельно для загрузки в другой чат.
Данные находятся в личном каталоге приложения. При удалении экспериментальной версии Android может удалить и её локальные записи; перед удалением экспортируй их.

## Системные разрешения и приватность
- Notification Listener — широкий доступ Android ко всем уведомлениям; собственный код фильтрует медиасобытия только указанных приложений, но само полномочие шире. Пользователь должен осознанно согласиться.
- Microphone — только после отдельного включения «Магира». Перед записью спросить согласие участников.
- Internet — **только для скачивания модели**. Никакой передачи музыкального журнала или аудиозаписей на сервер.
- Foreground service, partial wake lock — для длинной записи и обработки при заблокированном экране.

## Установка
0.5 имеет новый applicationId (`ru.chanti.slushaet.v05`), поэтому ставится **рядом** с 0.4; можно проверить, не удаляя старую установку. У экспериментальных сборок GitHub Actions нет постоянной release-подписи; в следующих версиях понадобится отдельный стабильный ключ подписи для обновлений без переустановки. Перед удалением старых версий экспортировать записи.

**Это beta-прототип.** Android-компиляция не подтверждает безошибочную работу на конкретном телефоне; необходимо протестировать 15–20 минут записи с выключенным экраном, экспорт ZIP, качество русского текста на короткой записи, затем нагрузку 2–4 часа.
