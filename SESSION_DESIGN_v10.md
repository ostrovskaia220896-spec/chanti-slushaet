# Архитектура сессий «Миров Магира» — v1.0

## Инварианты
1. Сессия — отдельная папка `Magir_...`; папки создаются эксклюзивно, без перезаписи при совпадении времени.
2. Выбранная сессия, активная запись и активная расшифровка — разные состояния.
3. Whisper получает явный `session_name` в Intent и работает только с этой папкой.
4. На устройстве работает не более одного Whisper worker; остальные задачи стоят в сохраняемой очереди.
5. Каждая завершённая часть имеет checkpoint `part_NNNN.whisper.txt`; возобновление пропускает готовые части.
6. Текущий/аварийный фрагмент имеет суффикс `.m4a.pending`; Whisper видит только `.m4a`.
7. Аудио и тексты не удаляются автоматически.

## Структура каталога
```
Magir/
  Magir_YYYYMMDD_HHMMSS_mmm/
    session.properties
    part_0001.m4a
    part_0002.m4a.pending
    part_0001.whisper.txt
    transcript_whisper_ru.txt
    transcript_whisper_ru.tmp
```

- `.m4a` — успешно завершённый AAC-фрагмент.
- `.m4a.pending` — незавершённый файл; сохраняется в ZIP, но не отправляется Whisper автоматически.
- `.whisper.txt` — текст одного фрагмента.
- `transcript_whisper_ru.txt` — общий TXT; замена идёт через временный файл и backup.
- `session.properties` — время создания/остановки.

## Очередь распознавания
- Проверяется существование сессии, наличие завершённого аудио и наличие готовых checkpoint.
- Повторный запрос одной сессии не создаёт дубликат задачи.
- Активная задача фиксируется отдельно от очереди.
- После завершения задачи запускается следующая.
- Если Android завершил процесс, устаревший флаг `running` очищается; готовые checkpoints остаются. Пользователь может повторно запустить незавершённую сессию.
- Показывается реальное прошедшее время и номер части. Процент внутри нативного вызова Whisper не выдумывается.

## Восстановление
- При старте приложение проверяет backup-файлы: если целевой файл есть — удаляет старую копию; если целевого нет — возвращает backup.
- Незавершённые каталоги ZIP-импорта `.partial` очищаются после перезапуска процесса; исходный ZIP не изменяется и его можно импортировать снова.
- Незавершённые `.m4a.pending` сохраняются для ZIP-экспорта/ручной диагностики.

## Безопасный ZIP-импорт
Принимаются только плоские имена:
- `part_NNNN.m4a`
- `part_NNNN.m4a.pending`
- `part_NNNN.whisper.txt`
- `transcript_whisper_ru.txt`
- `transcript_imported_ru.txt`

Пути с каталогами, traversal-имена и посторонние файлы не распаковываются. Ограничены число файлов и суммарный размер распаковки.

## Приёмочные сценарии
- Запись 30+ минут с заблокированным экраном; финализированные M4A открываются.
- Прерывание записи: предыдущие M4A целы, текущий `.pending` не выдаётся за готовый.
- Запустить ASR для сессии A, начать запись B: A продолжает в собственной папке.
- Добавить B в очередь: она стартует после A; два Whisper-процесса одновременно не запускаются.
- Прервать ASR и повторить: готовые checkpoints не пересчитываются.
- Экспортировать A во время записи B.
- Импортировать ZIP/TXT из старых версий, не изменив оригиналы.
- Обновить подписанный APK поверх предыдущего `ru.chanti.slushaet`, сохранив модель и сессии.
