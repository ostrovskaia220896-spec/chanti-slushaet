# Чанти слушает v0.3

Одна кнопка начинает и останавливает музыкальный журнал. Автоматически записываются события проигрывания Яндекс Музыки через доступные Android MediaSession метаданные. Доступ к уведомлениям широкий и включается только осознанно. Лайки помечаются подтверждёнными только если Яндекс отдаёт рейтинг. Передача событий именно в существующий чат автоматически ещё не реализована: официального интерфейса для произвольной фоновой отправки из APK в конкретный разговор ChatGPT нет. «Магир» — отдельная запись и передача в другой чат, без смешивания с музыкой.
